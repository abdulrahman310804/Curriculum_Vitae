# Portofolio Abdul Rahman

Website portofolio profesional Abdul Rahman, lulusan S1 Pendidikan Teknologi Informasi Universitas Lampung. Portofolio menampilkan pengalaman dalam administrasi digital, teknologi, pendidikan, pengembangan web, dan produksi konten kreatif.

## Halaman publik

https://abdulrahman310804.github.io/Curriculum_Vitae/

## Isi portofolio

- Profil profesional dan arah karier
- Pengalaman di Bank BRI, Kampus Mengajar, Universitas Lampung, dan AT Store
- Proyek administrasi digital, portal informasi, media pembelajaran, dan sistem rapor
- Keahlian administrasi, web, desain, pendidikan, dan pemanfaatan AI
- Pencapaian akademik, organisasi, pelatihan, dan sertifikasi
- Tautan kontak profesional

## Teknologi

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Menjalankan secara lokal

Buka `index.html` menggunakan peramban atau ekstensi Live Server. Website tidak memerlukan proses instalasi atau build.

## Catatan sebelum publikasi

Informasi pada website telah disesuaikan dengan CV terbaru September 2026. Berkas `cv-abdul-rahman.pdf` tersedia melalui tombol “Unduh CV Terbaru”.
